# Dedicated private Prometheus chart

Requires immutable Prometheus image digest and a centrally reviewed external ConfigMap with key `targets.json`, produced from current authoritative ESS inventory. Each target group must include env, db_proxy_code, target_db_code and ecs_instance_id labels. Do not supply guessed/static IPs and call them live inventory. This chart creates no inventory controller, cloud access, role grant or Argo Application. Stale inventory must be refused by Infra API independently against fresh provider node membership.

Only matching catalog associations and nonempty node identities are scraped. `honor_labels=false` prevents exporter labels overriding inventory labels; `honor_timestamps=false` uses direct scrape time. For pinned PgCat fresh in-process exporter snapshots this is observation time; cached exporters are not qualified. Rules preserve raw observation time, exclude incomplete/duplicate client metric families, and never map an absent node to zero. Infra API must still check up=1, sample age <=15 seconds, full expected pools/node inventory and identity/revision. Threshold and query acceptance remain central review dependencies.

Set `clientTargets` to all individual client replicas through a reviewed inventory mechanism. Empty list means no app scrape evidence; never treat that as zero errors. The private service has no authentication built by this chart; central network policy restricts Infra API/approved readers. Ephemeral bounded data retention is two hours/128MB; persist/export acceptance evidence externally before restart. No zero-loss result survives Prometheus restart merely because this workload becomes ready.
