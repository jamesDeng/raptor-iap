# Live-question wire fixtures

Generated by producer Go tests using production RequestInput/Fingerprint/Issued and Gateway Execution/LiveResult types. Values are synthetic and contain no usable credentials or cloud evidence.

Set CONTRACT_FIXTURE_DIR to this absolute fixtures directory and run TestExportQuestionContract from components/raptor/internal/agentaccess, then TestExportGatewayContract from components/agent-gateway/internal/execution. Consumers validate these wire outputs. Source baseline: Raptor ed59b78, Gateway 42d7511; integration base be2e840.

## Resource transport contract (source only)

`infra-resource-deployments.json` and `infra-resource-status.json` are generated by
`TestResourceReadObservationContract` in Infra's API package. Discovery has a
resource root and typed `applicationWorkloads`; it has no sample freshness time.
Status selects the returned opaque `workloadKey` and preserves the provider's
status timestamp. Run that test with the same `CONTRACT_FIXTURE_DIR` to regenerate.

`gateway-resource-execution.json` is generated alongside the historical Gateway
fixture by `TestExportGatewayContract`. It carries `evidenceVersion: 2`, transport
read-time discovery evidence, and actual status evidence. It contains no
`cloud_identity_get` or fabricated account-match observation. Gateway and Raptor
consumer tests cover this current fixture separately from the historical fixture.

The files without `resource` in their names describe the historical provider
selector contract. They remain readable test evidence; they do not authorize new
resource-contract execution. These synthetic fixtures establish source parity,
not deployed cloud observations, qualification PASS, or an image release.
