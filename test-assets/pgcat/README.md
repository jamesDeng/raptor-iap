# Pinned PgCat test package

`source-pin.json` pins public source to an exact commit. `pgcat.toml.tmpl` is a private-rendering contract with client/backend TLS enabled and static pools; there is no published Linux/ECS image or deployed PgCat established by this directory. Never substitute `latest` or an unqualified image. `compose.yaml` is optional local tooling and requires a privately rendered configuration and an immutable digest supplied by the owner.

The local integration test in `components/test-client/internal/traffic/pgcat_integration_test.go` qualifies zero, idle, active and multiple pool clients against a source-built PgCat fixture. Exporter normalization uses `pgcat_pools_cl_active + pgcat_pools_cl_idle + pgcat_pools_cl_waiting`, aggregated per node across pools/users. It excludes incomplete or duplicate metric families rather than substituting zero; observation timestamps preserve the raw scrape timestamp. See `../metrics/recording-rules.yaml` and fixtures.

Static pools are part of this qualification. The pinned upstream source ignores clients whose pool is no longer in the current pool lookup. Do not hot-reload/remove pools during this test. Config revision change, missing expected pool/user families, absent node inventory, `up != 1`, missing labels or observations older than 15 seconds must refuse safety use. Rule arithmetic alone cannot detect an entire missing pool: Infra API's reviewed coverage contract must supply expected pool/node identity. These thresholds remain proposed central contracts, not implemented API gates.

Omit `autoreload` to disable it. In this pin, `autoreload=0` creates a zero-duration Tokio interval and is invalid. The raw source exporter observes current in-process client stats; the Prometheus scrape timestamp represents observation only for fresh direct scrapes without an intermediate cache. Do not refresh cached observations. Idle backend server counts and running query counts are not client counts. No extra custom admin exporter is needed for the qualified static-pool experiment.
